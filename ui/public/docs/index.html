How do I get a trace file?

WideScope reads a JSON trace you already have. The friction is producing one. Below are copy-paste recipes to export a trace from the common LLM stacks, then just drag the file into the editor — it's parsed in your browser and never uploaded.

The 3 shared lines every Python recipe uses

Each SDK below reuses one tiny exporter that writes an OTLP-JSON file WideScope can open. Drop this next to your script as write_otlp.py:

write_otlp.py

import json
from google.protobuf.json_format import MessageToDict
from opentelemetry.exporter.otlp.proto.common.trace_encoder import encode_spans
from opentelemetry.sdk.trace.export import SpanExporter, SpanExportResult


class OtlpJsonFileExporter(SpanExporter):
    """Write all collected spans to a single OTLP-JSON file."""

    def __init__(self, path: str = "trace.json") -> None:
        self.path = path
        self._spans: list = []

    def export(self, spans) -> SpanExportResult:
        self._spans.extend(spans)
        payload = MessageToDict(encode_spans(self._spans))
        with open(self.path, "w") as f:
            json.dump(payload, f, indent=2)
        return SpanExportResult.SUCCESS

    def shutdown(self) -> None:
        pass

Wire it into a tracer once, before you call the model:

from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import SimpleSpanProcessor
from write_otlp import OtlpJsonFileExporter

provider = TracerProvider()
provider.add_span_processor(SimpleSpanProcessor(OtlpJsonFileExporter("trace.json")))
trace.set_tracer_provider(provider)

Every recipe below adds exactly one instrumentation line to this setup. Install the shared bits with pip install opentelemetry-sdk opentelemetry-exporter-otlp-proto-common.

01OpenAI SDK

pip install openinference-instrumentation-openai, then instrument before your first request:

from openinference.instrumentation.openai import OpenAIInstrumentor
OpenAIInstrumentor().instrument()

# ... your normal OpenAI calls ...
from openai import OpenAI
OpenAI().chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "hello"}],
)

When the script exits, trace.json holds every prompt, completion, and token count. Drag it in.

02Anthropic SDK

pip install openinference-instrumentation-anthropic:

from openinference.instrumentation.anthropic import AnthropicInstrumentor
AnthropicInstrumentor().instrument()

from anthropic import Anthropic
Anthropic().messages.create(
    model="claude-sonnet-5",
    max_tokens=256,
    messages=[{"role": "user", "content": "hello"}],
)

03LangChain / LangGraph

pip install openinference-instrumentation-langchain. One instrumentor covers chains, agents, and LangGraph nodes:

from openinference.instrumentation.langchain import LangChainInstrumentor
LangChainInstrumentor().instrument()

# ... build and .invoke() your chain / graph as usual ...

Each chain step, tool call, and LLM span lands in trace.json as a nested waterfall.

04Generic OpenTelemetry collector → JSON file

Language-agnostic. If your app already exports OTLP over the wire, point it at a local collector whose file exporter writes the trace to disk. No code changes.

otel-collector-config.yaml

receivers:
  otlp:
    protocols:
      http:
        endpoint: 0.0.0.0:4318

exporters:
  file:
    path: ./trace.json

service:
  pipelines:
    traces:
      receivers: [otlp]
      exporters: [file]

Run the collector, then send your app's spans to it:

otelcol-contrib --config otel-collector-config.yaml

# in your app's environment:
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318

The file exporter writes newline-delimited OTLP JSON — one batch per line. If your run produced several lines, drag a single line into WideScope (each line is a complete resourceSpans document), or lower your batch settings so the whole trace flushes at once.
